# 抽名字 - Random extraction

版本：v2.0  
开发者：tao  
更新时间：2026.09  

---

## 一、软件简介

抽名字是一款基于 Python + Tkinter 开发的随机抽奖工具。

软件支持：

- Excel名单导入
- 随机抽取幸运人员
- 多轮抽奖
- 自动去除已中奖人员
- 中奖历史记录
- 快捷键操作

适用于：

- 年会抽奖
- 公司活动
- 班级点名
- 课堂互动
- 福利抽取
- 活动签到抽签

# 四、环境配置

## 方法一：自动配置

双击：

```
setup_env.bat
```

等待安装完成即可。

---

## 方法二：手动安装

进入项目目录：

```
cd 项目路径
```

安装依赖：

```
pip install -r requirements.txt
```

如果Excel读取失败：

执行：

```
pip install openpyxl
```

# 五、启动软件

运行：

```
python main.py
```

启动后进入抽奖界面。

---

# 六、使用说明

## 1. 导入名单

菜单：

```
文件 → 打开
```

选择Excel文件。

Excel格式要求：

|姓名|
|-|
|张三|
|李四|
|王五|

必须包含：

```
姓名
```

列。

---

## 2. 设置抽奖人数

菜单：

```
设置 → 抽奖人数
```

设置每轮需要抽取的人数。

例如：

```
每轮抽取：5人
```

---

## 3. 开始抽奖

点击：

```
开始
```

或者快捷键：

```
Enter
```

系统会：

1. 随机滚动姓名
2. 显示中奖人员
3. 保存中奖记录
4. 移除中奖人员

---

# 七、抽奖规则

## 随机机制

软件使用：

```
random.SystemRandom()
```

进行随机选择。

特点：

- 每轮随机
- 不重复中奖
- 无人工干预

---

## 抽奖池机制

例如：

原名单：

```
张三
李四
王五
赵六
```

第一次抽：

```
张三
李四
```

剩余：

```
王五
赵六
```

下一轮不会再次抽到：

```
张三
李四
```

---

## 数据安全

注意：

中奖人员移除只发生在：

```
内存抽奖池
```

不会删除：

```
names.db
```

重新打开程序：

原始名单仍然存在。

---

# 八、中奖历史

软件自动保存：

```
history.db
```

记录内容：

- 抽奖时间
- 中奖人员

查看：

菜单：

```
设置 → 中奖历史
```

显示：

```
最新记录优先
```

# 九、快捷键

|快捷键|功能|
|-|-|
|Enter|开始抽奖|

# 十、常见问题

## 1. Excel无法读取

安装：

```
pip install openpyxl
```

---

## 2. 中文显示异常

检查：

- 系统中文字体
- Tkinter字体设置

推荐：

```
宋体
楷体
微软雅黑
```

---

## 3. 数据库不存在

首次运行自动创建：

```
names.db
history.db
```
